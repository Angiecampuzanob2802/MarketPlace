# 🛍️ MarketPlace

Aplicación desarrollada para la gestión y visualización de productos, utilizando **Angular** como framework principal para el desarrollo de la aplicación y **Ionic** para la construcción de la versión móvil.

El proyecto fue desarrollado aplicando conceptos de desarrollo de aplicaciones web y móviles, utilizando componentes, servicios, navegación y una estructura organizada por páginas.

## 🚀 Tecnologías principales

### 🅰️ Angular

**Angular** es el framework principal utilizado para el desarrollo de MarketPlace.

Se utilizó Angular para:

* Construcción de la interfaz de usuario.
* Desarrollo de componentes y páginas.
* Manejo de rutas y navegación.
* Creación y utilización de servicios.
* Organización de la estructura de la aplicación.
* Implementación de la lógica de negocio.
* Desarrollo utilizando **TypeScript**.

### 📱 Ionic

**Ionic Framework** fue utilizado para el desarrollo de la aplicación móvil.

Su integración con Angular permitió construir interfaces adaptadas a dispositivos móviles utilizando tecnologías web.

Ionic se utilizó principalmente para:

* Desarrollo de la interfaz móvil.
* Componentes visuales para dispositivos móviles.
* Navegación entre páginas.
* Diseño adaptable.
* Construcción de una experiencia orientada a aplicaciones móviles.

### ⚡ Capacitor

El proyecto utiliza **Capacitor** como parte de la integración para aplicaciones móviles, permitiendo llevar la aplicación desarrollada con Angular e Ionic hacia plataformas móviles.

## 🛠️ Tecnologías y herramientas

## 💻 Instalación

Para ejecutar el proyecto localmente es necesario contar con **Node.js** y las herramientas necesarias para Angular e Ionic.

### Instalar dependencias

Desde la carpeta del proyecto:

```bash
npm install
```

### Ejecutar con Angular

Para iniciar la aplicación utilizando Angular:

```bash
ng serve
```

La aplicación estará disponible normalmente en:

```text
http://localhost:4200
```

### Ejecutar con Ionic

Para ejecutar la aplicación utilizando Ionic:

```bash
ionic serve
```

La aplicación estará disponible normalmente en:

```text
http://localhost:8100
```

## 📱 Aplicación móvil

MarketPlace incorpora **Angular + Ionic + Capacitor** para el desarrollo de la aplicación móvil.

Esta integración permite utilizar Angular como base del proyecto, Ionic para la construcción de las interfaces móviles y Capacitor para la integración con plataformas móviles.
